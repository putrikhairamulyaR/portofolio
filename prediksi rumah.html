House Price Prediction

An end-to-end machine learning project to estimate fair market property values using Linear Regression and Streamlit.

📌 Project Overview

"A newer house is not always more expensive, and an older house is not always cheaper."

In today's real estate market, various developer incentives and marketing strategies can make newly built homes surprisingly affordable. As a result, property prices are influenced by far more than just the age of the house. Factors such as square footage, number of bedrooms, number of bathrooms, lot size, garage capacity, and neighborhood quality often play a much greater role in determining a property's value. Therefore, a data-driven analysis is essential to identify which factors have the strongest impact on house prices and to support more accurate property valuation.

This project utilizes historical housing data to build a predictive model. It takes into account key property characteristics such as Square Footage, Lot Size, Year Built, Number of Bedrooms and Bathrooms, Garage Size, and Neighborhood Quality. By deploying this model via an interactive Streamlit web application, users can easily input these specifications and receive an instant, data-driven price estimation.

🎯 Project Objectives

  • Perform Exploratory Data Analysis (EDA) to identify factors most correlated with house prices.
  • Build and train a Linear Regression model to predict continuous property values.
  • Deploy the trained model into a user-friendly Streamlit Web App for real-time inference.

🧾 EDA and Features

The exploratory data analysis focuses on finding linear correlations between property features and the final house price, analyzing the distribution of house ages, sizes, and neighborhood impact.

📈 Results & Insights

We compared three different algorithms to predict housing prices: Linear Regression, Decision Tree, and Random Forest. The evaluation demonstrated that factors like Square Footage, Neighborhood Quality, and Lot Size have the most significant impact on the final valuation.

Model MAE RMSE R² Score
Linear Regression 8,230.50 10,078.25 0.9984
Decision Tree 22,204.38 28,041.87 0.9878
Random Forest 16,470.59 19,761.61 0.9939

App Deployment: The best-performing model pipeline was exported using joblib and integrated into a professional Streamlit application, allowing users to get instant housing estimations through an intuitive Enterprise UI.
