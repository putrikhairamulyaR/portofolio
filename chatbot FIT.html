Chatbot FIT

A smart document-based chatbot designed to centralize guidelines, rules, and instructions.

▶ Watch on YouTube

📌 Background

This application was initiated because the guideline, rule, and instruction documents at FIT (Faculty of Applied Science) were scattered. Chatbot FIT was built to facilitate information search and retrieval for users, making it easier for the study program to convey information and reduce miscommunication.

🎯 Key Features

  • Large Language Model (LLM): Uses Ollama Qwen Instruct 2.5 equipped with login attempt limits to maintain security.
  • Admin Dashboard: Equipped with an admin feature to control user data and track which documents are most frequently accessed by users.
  • Real-Time Sentiment Analysis: User feedback on chatbot responses is analyzed in real-time using a Majority Voting method from three sentiment analysis models: VADER, TextBlob, and SentiWordNet.
  • Smart Document Management: Uses Qdrant as the Vector Database and BERT Multi-lingual as the Embedder. Documents can be updated or removed, and it includes sub-domain categorization to refine search results within the chatbot.
  • Deployment-Ready: Built using Docker, making it ready to be deployed across various environments.

🌟 Achievements

This project was exhibited live at TULT Telkom University in 2026, attended by several industry representatives, and received highly satisfactory evaluations.
